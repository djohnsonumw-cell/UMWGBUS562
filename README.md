# UMWGBUS562
Repository for GBUS562

## About

This repository holds materials created for GBUS 562 (AI Language Models) at the University of Mary Washington. The content is organized into weekly folders, one for each week of the course.

## Weekly Work

1. week-01: Connect 4, a single-page browser game. Play against a computer opponent with three difficulty levels, or switch to two-player mode and take turns with a friend.
